# 스네이크 게임 🐍

HTML, CSS, JavaScript(바닐라)로 만든 브라우저 스네이크 게임입니다. 별도 설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 실행 방법

1. 이 저장소를 클론하거나 다운로드합니다.
2. `index.html`을 브라우저에서 엽니다.
3. **게임 시작** 버튼을 누르고 방향키(↑ ↓ ← →)로 뱀을 조종합니다.

## 기능

- 400x400 캔버스, 20x20 격자
- 먹이를 먹으면 뱀이 길어지고 +10점
- 벽이나 자기 몸에 부딪히면 게임 오버
- 최고 점수를 LocalStorage에 저장
- **난이도 선택**: 쉬움(200ms) / 보통(150ms, 기본) / 어려움(100ms) / 매우 어려움(50ms)
- **일시정지 / 재개** 버튼
- **레벨 시스템**: 50점마다 레벨업, 레벨업 시 이동 간격이 10ms씩 줄어 속도 증가 (최소 20ms)
- **효과음**: 시작 / 먹이 / 레벨업 / 게임 오버 / 최고 기록 (Web Audio로 합성, 소리 켜기·끄기 버튼 제공)
- 파티클, 빛 효과, 화면 흔들림 등 그래픽 효과

## 파일 구조

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 (점수판, 캔버스, 버튼) |
| `style.css` | 스타일 |
| `main.js` | 게임 로직, 렌더링, 사운드 |
